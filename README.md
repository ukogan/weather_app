# Solfege Trainer - Fixed Do vs Movable Do

An educational web application that helps musicians understand and compare the two main solfege systems used worldwide.

## Features

- **Classical Music Themes**: Play famous melodies including:
  - Ode to Joy (Beethoven)
  - Twinkle Twinkle Little Star
  - Canon in D (Pachelbel)
  - Eine Kleine Nachtmusik (Mozart)
  - Fur Elise (Beethoven)
  - Moonlight Sonata (Beethoven)
  - Spring from Four Seasons (Vivaldi)
  - Minuet in G (Bach)

- **Dual Solfege Display**: See notes displayed in both systems simultaneously
- **Speech Synthesis**: Hear the solfege syllables spoken aloud
- **Interactive Piano**: Visual keyboard that highlights notes as they play
- **Adjustable Tempo**: Control playback speed from 40-180 BPM
- **Note History**: Track all notes played with their solfege names

## Understanding the Systems

### Fixed Do
In Fixed Do, each solfege syllable always corresponds to a specific pitch:
- **Do** = C (always)
- **Re** = D (always)
- **Mi** = E (always)
- And so on...

This system is common in France, Italy, Spain, and Latin America.

### Movable Do
In Movable Do, the syllables represent scale degrees relative to the key:
- **Do** = 1st scale degree (tonic)
- **Re** = 2nd scale degree
- **Mi** = 3rd scale degree
- And so on...

This system is common in the USA, UK, and Germany, and is particularly useful for ear training.

## Usage

1. Open `index.html` in a modern web browser
2. Select a classical theme from the dropdown
3. Adjust tempo if desired
4. Choose which solfege system(s) to hear spoken
5. Click "Play Theme" to start
6. Watch the piano, note display, and history as each note plays

## Technical Details

- Pure HTML, CSS, and JavaScript (no frameworks required)
- Uses Web Audio API for tone generation
- Uses Speech Synthesis API for spoken solfege
- Responsive design works on desktop and mobile
